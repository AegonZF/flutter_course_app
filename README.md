# 📱 Flutter Poll App

Welcome to the **Flutter POll App**! This repository contains a complete Flutter application built to demonstrate core development concepts, clean architecture, and backend integration.

## ✨ Features

* **User Authentication**: Secure login and sign-up functionality.
* **Firebase Integration**: Real-time data management and backend support.
* **Responsive UI**: Beautiful and adaptable user interface for multiple screen sizes.
* **Cross-Platform**: Runs smoothly on Android, iOS, and Web.
* **State Management**: Efficient data handling across the app.

## 🛠️ Prerequisites

Before you begin, ensure you have met the following requirements:

* **Flutter SDK**: [Install Flutter](https://flutter.dev/docs/get-started/install)
* **Dart SDK**: Included with Flutter.
* **VS Code / Android Studio**: For code editing and debugging.
* **Git**: Version control system.

## 🔌 API Used

This project relies on the following key services:

* **[Firebase Console](https://console.firebase.google.com/)**:
    * **Authentication**: For managing user identities.
    * **Cloud Firestore / Realtime Database**: For storing app data.

## 🏃‍♂️ Usage

Follow these steps to run the project locally:

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/AegonZF/flutter_course_app.git](https://github.com/AegonZF/flutter_course_app.git)
    ```

2.  **Navigate to the project folder:**
    ```bash
    cd flutter_course_app
    ```

3.  **Install dependencies:**
    ```bash
    flutter pub get
    ```

4.  **Run the App:**
    ```bash
    flutter run
    ```

> **Note:** You may need to configure your own `google-services.json` (Android) or `GoogleService-Info.plist` (iOS) from your Firebase console if the existing configuration is restricted.
